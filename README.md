## 先说结论：搬瓦工晚高峰速度主要取决于线路，不是单看带宽

搬瓦工官网将 CN2 GIA/CTGNet 定位为面向中国大陆访问的优化网络。官网说明，普通 ChinaNet 线路在高峰时段可能出现拥堵，而 CN2 GIA 的主要价值是改善中国方向的网络稳定性。官方还表示，洛杉矶 USCA_9 机房同时接入中国电信 CN2 GIA、中国移动 CMIN2 和中国联通 Premium，并提供本地互联。

这意味着几个常见误区需要先纠正：

- **1Gbps 不等于中国大陆用户一定能跑满 1Gbps。**
- **机器配置高，不代表跨境网络晚高峰一定稳定。**
- **白天速度快，不代表晚高峰没有丢包或抖动。**
- **同一个品牌的不同机房，访问体验可能差别很大。**
- **同一个机房，电信、联通和移动用户也可能得到不同结果。**

如果你的目标是搭建面向中国大陆访问的网站、远程办公服务、代码仓库、个人应用或低延迟连接，优先级通常应该是：

1. 晚高峰丢包率；
2. 延迟波动；
3. 三网表现是否均衡；
4. 下载和上传速度；
5. 最后才是 VPS 标称端口和 CPU 配置。

网络线路像道路，VPS 的 1Gbps 或 2.5Gbps 更像车辆最高时速。道路堵了，车再好也只能跟着排队。

## 怎么判断晚高峰速度是否真的好？

### 1. 不要只看下载峰值

测速页面显示的峰值速度很容易让人兴奋，但它不一定代表真实使用体验。晚高峰更应该关注：

- 平均下载速度；
- 最低下载速度；
- 延迟平均值；
- 延迟抖动；
- 丢包率；
- TCP 重传；
- 多线程和单线程差异；
- 电信、联通、移动之间的差异。

例如，一台服务器白天下载速度可以达到 100MB/s，晚上下降到 10MB/s，但延迟依然稳定、丢包很低，那么它可能仍然适合运行网站或远程服务。另一台服务器测速能达到 50MB/s，但晚高峰频繁丢包，网页加载和 SSH 连接反而更容易卡顿。

### 2. 三大运营商要分开测

中国电信、联通和移动的出境线路不是同一条路。一个机房对电信用户表现不错，不代表移动用户也一样。

比较实用的测试方式是：

1. 使用电信宽带测试一次；
2. 使用联通宽带或手机热点测试一次；
3. 使用移动宽带或手机热点测试一次；
4. 分别在白天和晚高峰记录结果；
5. 连续几天观察是否有明显规律。

如果你只服务一种运营商的访客，例如公司员工主要使用电信宽带，那么不必为了“三网平均分”牺牲所有预算。但如果网站访客来自全国各地，三网表现就更值得重视。

### 3. Ping 低不等于访问快

延迟可以帮助判断响应速度，但它不能单独代表下载性能。

简单理解：

- Ping 低：服务器回应得快；
- 丢包少：连接不容易反复重传；
- 吞吐高：大文件下载更快；
- 抖动小：视频、远程桌面和实时连接更稳定。

对于网页、API 和 SSH，延迟与丢包比峰值带宽更重要。对于备份、镜像同步和大文件下载，吞吐量才更关键。

## 搬瓦工晚高峰测速的推荐方法

购买或迁移之前，可以按下面的方法做一次相对完整的判断：

1. 选择目标机房的测试 IP 或测速文件。
2. 在上午、下午和晚上分别测试。
3. 连续测试至少 3 天。
4. 每个时间段记录 Ping、丢包、下载速度和延迟波动。
5. 使用单线程和多线程各测一次。
6. 用不同运营商网络分别测试。
7. 测试网页访问、SSH 连接和大文件下载。
8. 观察高峰结束后是否恢复。

如果没有多个运营商环境，可以使用手机热点补充测试。手机网络不等于固定宽带，但至少能帮助发现某个地区或运营商是否明显不稳定。

测试时还要注意本地因素。家中 Wi-Fi、路由器负载、后台下载、VPN、中继线路和测速服务器本身，都可能影响结果。一次异常结果不能直接证明整个机房都差。
